# Historical generation-3 transition

This was a historical preproduction transition. Its original acceptance evidence
remains under `docs/audits`; it is not an executable procedure for current deployments.
That preproduction deployment and its update controller were retired. The
separately authorized temporary RN staging project does not restore this procedure.

Current supported forward transitions and preservation requirements are defined
in [operator upgrades](operator-upgrade.md). Generation 3 has no supported current
operator upgrade path. Code rollback does not reverse database DDL.
